# Post-Quantum-Secure-Chameleon-Hash-Functions-for-Redactable-Blockchains-A-Survey
This article surveys the intersection of post-quantum cryptography and redactable blockchain. Where existing surveys organise the field by redaction mechanism and trapdoor management, we take the post-quantum frontier as our subject and measure it against the classical state of the art. 

It is uploaded here to make my work more accessible, pending ACM DLT publication.
The PDF is named ACM_DLT_Submission_Ready.pdf
